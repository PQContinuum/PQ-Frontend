Sistema de Límites TTS (Text-to-Speech)

Fecha: Diciembre 2024
Versión: 1.0

1. Resumen Ejecutivo

El sistema de Text-to-Speech (TTS) utiliza la API de OpenAI para convertir texto a audio. Para mantener la rentabilidad del servicio, se han establecido límites de uso por plan de suscripción.

Costo base OpenAI TTS: ~$0.01 USD por reproducción (promedio)

Objetivo: Mantener el costo de TTS ≤ 25-30% del precio del plan

6. Fórmula de Cálculo

Costo por reproducción:
Costo = (caracteres / 1000) × $0.015 USD

Estimación promedio:
~400 caracteres por chunk × $0.015/1000 ≈ $0.006 USD
+ overhead de API ≈ $0.01 USD/reproducción

7. Implementación Técnica

7.1 Archivos Clave

  • lib/memory/plan-limits.ts - Configuración de límites
  • lib/tts-usage.ts - Tracking de uso
  • app/api/tts/route.ts - API endpoint con verificación
  • db/schema.ts - Tabla tts_usage

7.2 Flujo de Verificación

  1. Usuario solicita TTS → API recibe request
  2. Se obtiene el plan del usuario (tabla subscriptions)
  3. Se cuentan reproducciones del día/mes (tabla tts_usage)
  4. Si está bajo el límite → genera audio → registra uso
  5. Si excede límite → retorna error 429 con mensaje

7.3 Estructura de Base de Datos

Tabla: tts_usage
- id: UUID (PK)
- user_id: UUID
- character_count: INTEGER
- voice_used: VARCHAR(50)
- created_at: TIMESTAMP WITH TIME ZONE

8. Mensajes de Error

Código Condición Mensaje

9. Recomendaciones de Ajuste

Para ajustar límites:
1. Editar lib/memory/plan-limits.ts
2. Modificar los valores en TTS_LIMITS
3. Reiniciar el servidor

Consideraciones:
  • Mantener costo TTS ≤ 30% del precio del plan
  • Free: subsidio aceptable para adquisición
  • Monitorear uso real para ajustar límites
